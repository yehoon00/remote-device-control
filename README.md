# 🌐 TCP/IP 기반 멀티스레드 원격 장치 제어 시스템

> **VEDA 심화 실습 평가 2 (리눅스 프로그래밍)**
> 우분투 리눅스(Client)와 라즈베리파이 4(Server) 간의 TCP 소켓 통신을 이용한 비동기 임베디드 주변 장치 제어 프로젝트입니다.

---

## 🛠️ 개발 환경 및 시스템 구조

- **Server**: Raspberry Pi 4 (Raspberry Pi OS)
- **Client**: Ubuntu Linux PC
- **통신 프로토콜**: TCP/IP Socket (Port: 5100)
- **대상 장치**: LED (소프트웨어 PWM), 부저, 조도 센서, 7세그먼트 (BCD 디코더 연동)

---

## ✨ 핵심 구현 특징

1. **동적 공유 라이브러리 (.so) 모듈화**
   - 주변 장치 제어 로직을 독립적인 `.so` 파일로 분리하여 빌드 타임 의존성을 낮추고, 서버 소스코드 재컴파일 없이 모듈 단위 업그레이드가 가능한 구조 확보
2. **백그라운드 데몬(Daemon) 프로세스**
   - 서버는 `daemon(0,0)`을 통해 제어 터미널과 세션을 분리하여 백그라운드 상시 서비스 형태로 구동
3. **POSIX 스레드 기반 비동기 처리 및 동기화**
   - 다중 클라이언트 접속 처리 및 센서 모니터링을 위한 멀티스레드 아키텍처
   - 7세그먼트 카운트다운 자원 제어 시 데이터 레이스 방지를 위해 `pthread_mutex_t` 동기화 적용
4. **시그널 방어벽 처리**
   - 클라이언트의 강제 종료 상황 시 서버 다운을 방지하는 `SIGPIPE` 무시(`SIG_IGN`) 및 `SIGTSTP` 오작동 차단
